# Code of Conduct

Pyramz adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be welcoming, be respectful, give and accept constructive feedback gracefully, and focus on what's best for the community. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests, discussions or any other project space.

## Reporting

To report unacceptable behaviour, contact the maintainers at **287877668+karawash-projects@users.noreply.github.com**, or report it privately on GitHub through [a private security advisory](https://github.com/karawash-projects/pyramz/security/advisories/new) (it reaches only the maintainers). All reports will be reviewed promptly and kept confidential. Maintainers may remove comments or contributions, or temporarily or permanently ban contributors, in line with the enforcement guidelines of the Contributor Covenant.
